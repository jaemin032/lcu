## Original host and standalone wiring

The previous analyzer reported that it could not find a native-pipe host. The installed `app.asar` had SHA-256 `2551cba1057a05cdc5cf5d75b146fac4092bff4ce77a10c43e3286c88d24c82d`. [Reverse Engineer Anything](https://github.com/morluto/rea) 6.9.0 inventoried the archive and statically analyzed the selected host declaration in `.vite/build/early-bootstrap-331-29198f5b57adf59a.js`. The full chunk exceeded REA's 1 GiB JavaScript worker budget. Its archive scan also recorded eight integrity contradictions in unpacked native files. The selected JavaScript declaration was read from the packed chunk. Acorn established its exact lexical placement.

The original server factory is now the default for a destructured `startServer` option on a wrapper called by the Electron startup function. That original factory accepts the four existing path and pipe options and returns `pipePath`, `closeActiveTurn`, `hasActiveTurn`, and `dispose`. LCU recognizes the layout by its syntax and options, and carries the factory expression verbatim with its module-scope dependencies. Extraction refuses a supplied `startServer` override or dependencies on either enclosing function's local bindings. The existing webpack adapter loads the dependencies and the existing Windows launch entry supplies the paths and lifetime wiring.

A follow-up probe alternated a Stop after approved capture and an Interrupt after discovery on one connection. Four of twelve turns left an original helper running. Both categories could leave the helper behind. The installed `@oai/sky` Window2 client registers an `end_turn` handler in `targets/windows/internal/computer_use_client_base.js`. The original broker's `startServer` removes the tracked turn from its socket map after the helper replies to `end_turn`. The desktop app also calls `closeActiveTurn` on app-server `turn/completed`. In the failing standalone traces, the broker had already cleared the matching ID before LCU's separate lifetime signal reached `closeActiveTurn`. The original close returned `false`.

LCU now attaches a lifecycle adapter to the installed `WindowsHelperTransport`. It forwards the original `end_turn` request and uses its original turn metadata to call the broker's `closeActiveTurn` while that broker can still match the turn. A simultaneous standalone lifetime signal waits for the same cleanup. The adapter allows 1.5 seconds for a stuck `end_turn` before asking the original broker to close and continues to use the direct lifetime signal when the runtime sends no `end_turn`. Every other request and the underlying transport stay in the original Windows implementation. The unit fixture covers simultaneous cleanup, stale IDs, duplicate requests, and a stuck request. The same connected-guest test closed the helper on each of the twelve turns after this change.

The Window2 guest test also launched a locally built WinForms app through `sky.launch_app`, located it with `list_apps` and `list_windows`, rehydrated its window with `get_window`, and activated the intended window. The runtime emitted a screenshot of the target while the fixture's cover window remained in front. The fixture independently recorded the effects of `set_value`, coordinate click, scrolling, dragging, right click, double click, and the advertised `Raise` secondary action.
